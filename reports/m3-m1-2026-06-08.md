# M3 문맥 분류 + M1 잔여 정리 — 2026-06-08

## M3 — 문맥 분류기 (numpy 로지스틱 회귀)

환경 제약(CPU 4코어·GPU 없음·torch 미설치)으로 docs/05의 KcELECTRA→ONNX 풀 파인튜닝은
이 사이클에서 비현실적 → **의존성 경량 numpy LR**로 1차 분류기 구현(정직한 단계화).
KcELECTRA는 동일 인터페이스(load→score)를 맞춰 GPU 단계 과제로 이월.

### 대조셋 (data/context/contrastive-b{1..5}.jsonl)
29개 ambiguous/common 용어 × harmful/benign 대조 문장 — **748행**(harmful 360 / benign 388).
benign에 동음이의(운지버섯·한남동·노무사·병신년 干支·어묵탕)·인용(F19)·대항표현(F20) 하드
네거티브 포함. ml-engineer 생성 → qa-redteam 적대 검증(라벨 교정·동음이의 보강·평가누수 제거).

### 모델 (models/context_clf.json, 620K)
- 피처: 문자 n-gram(2,3) + 단어 unigram 해시(2^18) + 보조(safe_context 등장·따옴표·메타담론).
- 학습: 클래스 가중 L2 LR, surface별 80/20 층화, 온도 스케일 캘리브레이션(T=0.9).
- **val 지표: accuracy 0.873 / precision 0.810 / recall 0.941 / F1 0.871 / AUC 0.951** (목표 F1≥0.85 충족).

### 엔진 통합 (src/noise_checker/context_classifier.py + engine.py)
- `ambiguity != unambiguous` 매치의 `context_score`를 **고정 0.5 → 분류기 harmful 확신도**로.
- 불변식 유지: context_score < 0.85면 ambiguous revise 캡(확신 없이 revise 불가), ≥0.85면 해제.
- 미탑재(모델 파일 없음) 시 0.5 폴백 — 하위호환(기존 테스트 불변). `NOISE_CONTEXT_MODEL` 로드.
- 경계(0.4~0.6) 매치에 flag `context_low_confidence` — 2차 LLM 판정 훅(호출 미구현, 설계만).
- M2 인용 휴리스틱은 저신뢰 보조 안전장치로 보존.
