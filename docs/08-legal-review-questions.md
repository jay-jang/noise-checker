# 08. 법무 검토 질의서 — 라이선스·표현 책임 (M0/M1 게이트)

> 작성 배경: 3-AI 교차 리뷰(reports/cross-review-2026-06-05.md) 합의 1 — CC BY-SA 전파 경계가
> 사업모델의 핵심 불확실성으로 판정됨. 아래 질의에 대한 법무 회신이 나올 때까지 각 항목의
> **보수적 기본값**(현행 docs/02·03·04에 반영됨)을 유지한다.

## 질의 목록

### Q1. SA 파생 서술의 API 응답 포함 = "배포"인가 (최우선)
- 사실관계: `term.origin_story`의 상당수가 위키백과·페미위키(CC BY-SA 4.0) 본문을 요약·재서술해 작성됨.
  유료 B2B API 응답(`origin.summary`)에 이 텍스트가 포함됨.
- 질의: ① 이 응답 전송이 CC BY-SA의 "공유(배포)"에 해당하는가? ② 해당 시 고객사가 받은 응답·고객사 산출물에
  SA 의무(동일 라이선스 공개)가 전파되는가? ③ "각색(adaptation)" 기준 — 요약·재서술이 파생저작물인가,
  사실 정보 추출(아이디어/사실은 저작권 비보호)인가? 재서술의 안전한 작성 기준은?
- **회신 전 기본값**: `provenance_class='share_alike_core'` 항목의 유래 서술은 응답에 직접 포함하지 않음
  (출처 링크+메타데이터만 — 03 §2 단계 4). 검출·등급 판정 자체는 사실의 사용으로 보고 제한하지 않음.

### Q2. 사전 아티팩트·DB의 SA 의무 범위
- 질의: 폐쇄형 SaaS 내부에서만 로드되는 릴리스 아티팩트(lexicon.json 등)는 "공유" 미해당으로 보는 것이
  맞는가? 추후 사전 패키지 외부 판매·온프레미스 배포 시 effective_license='CC BY-SA'로 충분한가?
- 기본값: 외부 배포 채널 없음. attribution.json은 모든 채널에서 생성·동봉.

### Q3. 학습 데이터 → 모델 가중치 라이선스 전이
- 사실관계: 문맥 분류기(KcELECTRA 파인튜닝)의 학습 데이터 일부가 CC BY-SA 코퍼스일 수 있음.
- 질의: 가중치가 파생저작물인지에 대한 현행 해석·리스크 수준. TDM(텍스트데이터마이닝) 면책 적용 여부.
- 기본값: 학습 데이터별 license provenance 기록(model card) + SA 코퍼스는 평가 전용으로 격리하고
  학습 포함은 회신 후 결정 (교차 리뷰 합의 5와 정합 — 모델은 ambiguous reranker로 역할 제한).

### Q4. excerpt 인용의 안전 범위
- 사실관계: `term_evidence.excerpt`(≤300자 DB 제약)에 뉴스·위키 발췌 저장, 내부 검수용.
- 질의: 비공개 내부 DB 보관 + 검수 목적 사용이 공정 인용 범위인가? 외부(검수 콘솔 외) 노출 금지로 충분한가?

### Q5. incident 실명·sample_text 거버넌스 확인
- 사실관계: 02 §3.7 — `disclosable=true` 전환은 법무 검토 필수, 외부엔 display_title만.
- 질의: 이 거버넌스로 명예훼손(사실적시 포함)·신용훼손 리스크가 충분히 차단되는가?
  내부 회귀 테스트 파일(must_catch.jsonl)에 실사고 문구를 평문 보관하는 것의 허용 조건은?
  (06 — 골든셋 공개/비공개 분리 백로그와 연동)

### Q6. usage_notice의 면책 효력
- 사실관계: 모든 응답에 "자문 의견·판정 아님·인사조치 근거 사용 금지" 고지 강제 (03 §4).
- 질의: 이 고지 + 약관(자문 정의, 경과실 배상 상한, 약관규제법 §7 한계)으로 ① 고객사의 오용(직원 징계 등)
  발생 시 당사 책임 절연이 되는가? ② 추가로 필요한 계약 조항은?

## 운영 규칙

- 각 질의의 회신은 이 문서에 회신일·요지·반영 docs 목록과 함께 추가 기록한다.
- Q1·Q3 회신 전에는 해당 기본값을 완화하는 어떤 릴리스도 금지 (04 §5 게이트 0에서 강제).
- 분기 법령/판례 모니터링(04 §6)에 본 질의 관련 판례 추적을 포함한다.
